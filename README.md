# RISE

RISE AND BE KING, RISE AND RULE.

This repository now contains the first runnable Flutter implementation target for the RISE AI alarm clock, structured for iOS and Android. The implementation prioritizes the Decision File/Edge Case Bible requirements around resilient alarm state, audio-route safety, battery/permission messaging, and platform manifests.

## Run

```bash
flutter pub get
flutter test
flutter run -d android
flutter run -d ios
```
